# Third-party software and content

VerseCue distributes no paid or copyrighted Bible translation. For quoted-wording recognition only, it bundles two public-domain texts from eBible.org: the King James Version (1769 standard text, protocanon; public domain outside the United Kingdom, where Crown letters patent restrict printing) and the World English Bible (public domain). VerseCue never displays this text; it only uses it to recognise which verse a preacher is quoting. Displayed Bible text and presentation assets remain in the user's licensed ProPresenter installation. Sources and hashes: PUBLIC-DOMAIN-BIBLES.md.

Electron is distributed under the MIT license and contains Chromium, Node.js and their notices. Preserve the runtime's LICENSE and LICENSES.chromium.html in packaged output. Exact dependency versions and integrity hashes are recorded in package-lock.json. Playwright is a development test dependency and is not included in the desktop package. Packaging uses Electron's documented manual distribution layout without a third-party packaging framework.

Source checkouts do not contain whisper.cpp or model binaries. The optional Windows `--with-local-speech` development package includes only the previously verified official b5454 archive's CLI/shared libraries and base.en GGML model, checked against the recorded SHA256 values before copying. It preserves the upstream notices in WHISPER-LICENSE.txt and WHISPER-MODEL-LICENSE.txt. Native Mac speech assets remain separately required and unverified. No cloud recognizer is included. Sources and local pilot are recorded in RESEARCH_SOURCES.md.

The interface bundles unmodified fonts under the SIL Open Font License 1.1: Inter (ui/fonts/Inter-Variable.ttf, Google Fonts commit 0b58fb3, license in INTER-LICENSE.txt), DM Sans (ui/fonts/DMSans-Variable.ttf, Google Fonts commit 5b35b72, license in DM-SANS-LICENSE.txt) and IBM Plex Sans (ui/fonts/IBMPlexSans-*.woff2, license in IBM-PLEX-LICENSE.txt). Sources and hashes are in font-inventory.json. No artwork, cloud SDKs or Bible text datasets are included. Numeric reference metadata is the explicitly licensed exception described below.

Numeric KJV reference-numbering metadata is generated from the MIT-licensed openbibleinfo Bible-Passage-Reference-Parser4.0.0 (build-only dependency). Only canonical book/chapter verse counts are included in core/kjv-versification.json; no Bible text, apocryphal books or aggressive library parsing rules are shipped. Preserve REFERENCE-METADATA-LICENSE.txt. This metadata is not proof of installed Bible availability or exact-text/theme fidelity; other translations are not silently assigned KJV bounds.
