# Exact saved-passage lookup and reference intent

Small PR22 foundation extraction based on main after PR23/25. This adds read-only planning/resolution and the intent semantics required to keep its results current. It does not wire a new normal UI, save or trigger a passage, arm output or finish the ProPresenter integration.

The resolver searches bounded libraries for an exact normalized passage title and requested edition, validates every enabled nonempty cue in order and requires complete label coverage. Missing middle verses, unrelated cues, timelines, disabled/empty slides and ambiguous duplicate copies cannot become an arbitrary first selection. Split cues remain ordered parts. Same-chapter non-KJV coverage uses explicit requested labels without claiming verified edition numbering; AMP and AMPC remain distinct. Metadata never establishes genuine Bible text, formatting or physical rendering. Optional exact local provenance/warning callbacks cannot grant output authority.

The parser recognizes deterministic navigation intent, bounded offsets/ranges/repeat/chapter requests, hold and historical/negated wording. Session keeps a separate reference epoch so ordinary final preaching preserves pending lookup, while a new reference, hold, correction, partial revision, dismissal, expiry or lifecycle change cancels it. Negation inside ordinary preaching is not itself a correction. Input epoch still changes for every speech event, so this does not relax pending Auto cancellation. No new Auto policy or output permission is introduced.

The initial isolated extraction passed251/252 tests and exposed the old Session behavior: ordinary preaching canceled pending lookup. The required parser/navigation and small Session intent changes were included; the original failing regression was retained. After current main was incorporated, all269 module tests and JavaScript syntax checks passed. Tests use synthetic metadata/speech/HTTP, with no microphone or actual ProPresenter access. Matching Mac development build remains pending until its exact job finishes.

Normal coordinator/Confirm wiring, image review, native preparation/lifecycle, remote takeover checks, guarded Auto approval, real speech/latency and physical/service/platform acceptance remain separate PR22 deliverables. Adding this foundation is not a claim that those are implemented on main.
