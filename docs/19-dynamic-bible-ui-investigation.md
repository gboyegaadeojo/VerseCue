## Question and method
Can an unprepared passage be loaded and deliberately shown using the installed ProPresenter Bible UI, without external verse text or a prebuilt presentation? Can API readback safely identify that passage? Use existing computer-use skill/semantic controls where available, observe after each action, do not retry a timed-out write blindly. Read-only loopback probes remain under poc/. No Bible database extracted, no screenshots/private address dumps/verse text saved to repository.

Independent public research reconfirmed the vendor Bible UI workflow and macro/action guidance. Neither inspected documentation supplied a parameterized Bible-reference API/macro mechanism. The installed schema remains the stronger build-specific evidence. Absence from inspected documentation is not proof of unsupported behavior. Sources SRC-03/09 and new SRC-40/41 in RESEARCH_SOURCES.md.

## Important connector consequences — PROVISIONAL
The transient Bible buffer's UUID/name cannot be treated as an immutable passage identity. The same `Default` UUID appeared for different references, and regeneration made active-presentation/index unavailable while a prior preview remained. Bind every future command/context to exact reference/translation/content revision and reconcile state. If identity or translation cannot be verified, block automatic writes and relative context. Never equate “no active presentation” with “audience output blank.”

Accessibility data can lag screenshots and set-value completion can be uncertain. A last-resort implementation would require bounded completion checks, target/focus/ownership validation, cancellation handling and a fail-closed review path. Coordinate fallback successful in a supervised test does not prove a volunteer-safe unattended route. Screen scale/localization/multiple monitors/permission prompts/macOS parity, sustained responsiveness and concurrent Companion/operator safety are untested. No production UI automation module was written.

Physical output/fidelity cannot pass from this setup: only one personal audience screen plus stage screen configured, no church room/stream baseline, clipping warning unresolved, no running-media workload and no consented real sermon source yet. “Any reference loads in the Bible UI” is useful functional evidence but insufficient for P0.
