# Offline IBM Plex Sans typography

2026-11-18. User requested a more professional application typeface. Version0.5.5 replaces the operating-system default UI stack with IBM Plex Sans, using unmodified Regular400, Medium500, SemiBold600 and Bold700 WOFF2 files bundled under ui/fonts. Reference and page headings use a calmer medium weight, controls use medium, and small status/section labels avoid excessive bold. Reference/expiry figures use tabular numerals; source wording has explicit18px/1.6 line height. Existing sizes, target heights, layout, Figma direction and safety/IPC behavior remain unchanged.

Fonts were retrieved from official IBM/plex commit bc6a7e4b37634eb79785d59781893db63ee3edcb. Source, byte counts and SHA256 hashes are recorded in legal/font-inventory.json; the complete unmodified SIL Open Font License1.1 notice is included in legal/IBM-PLEX-LICENSE.txt. No system font installation, subscription, remote CDN, third-party font runtime or OS setting change is needed. Font packaging is offline on Windows and Mac. Primary sources: https://github.com/IBM/plex and https://github.com/IBM/plex/blob/master/packages/plex-sans/LICENSE.txt (checked2026-11-18).

The existing source/package verifier was extended to walk nested application assets so the four font binaries are covered by final source/manifest comparisons. It continues rejecting unlisted/mismatched package files. The focused own-app typography check waits for font readiness, verifies the actual reference/control family and all four loaded weights, and observes zero failed font requests and zero remote requests. It captures a local screenshot for visual review. Existing full/compact/scaling/smoothness desktop checks passed with the new typeface. Final packaged checks remain part of the release verification; this is not a booth-distance or screen-reader acceptance claim.

This is a focused cosmetic/packaging PR with no ProPresenter, speech-recognition policy, output-route or consent changes. Other full-application work and arbitrary-passage/service verification remain active.
