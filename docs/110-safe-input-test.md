The session must be resumed in dry run; testing enters Suggest-only and does not restore Auto or output afterward.

Capture ownership now distinguishes recognition and input-test leases. The backend expires input-test leases after10000ms, measured from acquisition, including time spent waiting for browser permission. Pause, Stop, reset, configuration changes, owner-window loss and departure from dry-run/Suggest revoke the lease. A stale timeout cannot cancel a new owner. Foreign windows cannot acquire or release it. The audio IPC rejects recognition requests on a test lease before calling the speech adapter, independently of the renderer's meter-only path.

The renderer uses the same exact-device/channel capture validation and health handling as normal listening. Test frames update the meter but never enter the speech-window buffer. Explicit Stop and expiry close tracks; a delayed permission result is discarded. A stopped request's late rejection cannot cancel a subsequent test.
