## Immediate external dependencies

- The native Mac route needs an authorized test installation and its real accessibility evidence before a profile can be implemented and claimed supported. Availability has been requested; Windows work does not imply that this gate passed.
- Unclipped native output needs the intended ProPresenter Bible styles to fit. Selection/correction by the operator or explicit authorization for separate named test styles has been requested. Existing style warnings remain blocking. A separate test style would not certify the church's original theme.
- Actual church audio, room/stream outputs, media/Companion coexistence and field acceptance need the corresponding hardware and observations. Neither synthetic targets nor a hosted runner can substitute for them.
- Permission to publish new personal-host evidence is separate from permission to run the tests. Until answered, code/build/synthetic results can be published while personal records stay ignored/private.

Continue safe implementation and verified checks where these dependencies do not apply. Do not merge PR22, call P0 passed or publish a replacement service release on the strength of this map.
