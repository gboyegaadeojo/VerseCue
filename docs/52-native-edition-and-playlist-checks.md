# Native edition and service-playlist checks

Date: 2026-11-18. Draft PR22, source version 0.6.0. Scope: the explicitly authorized personal Windows host, ProPresenter 21.4.2, loopback API. These are preparation tests, not a release, field acceptance or physical output verification.

## Implemented route

The existing experimental helper can now open the Bible workspace using its identified toolbar control, select an exact visible installed-edition name, verify the selected edition, atomically enter the canonical reference and wait for matching generated citation labels. It verifies foreground process, current accessibility bounds and hit testing before pointer input. It does not use generic slide navigation, trigger, Clear, theme, Look, macro or playlist-write commands. Unsupported or ambiguous controls fail closed. Unknown edition-menu outcomes do not claim that a Bible is definitely uninstalled.

Readiness polling now queries citation text rather than collecting every layout/image node on every poll. Clipping warnings are inspected separately after citation readiness. The worker remains bounded to twelve seconds; no timeout extension, output retry or security/permission change was introduced. Preparation still moves focus, pauses listening and disarms output. This is not background arbitrary preparation or a demonstrated sub-four-second route.

Saved-copy preparation now snapshots the focused service playlist's identity and contents before native work and rechecks the same playlist afterward. Changed or unverified playlist contents block completion. If no playlist was focused, the receipt explicitly reports that no playlist was checked. No automatic restoration, deletion or playlist modification is attempted.
