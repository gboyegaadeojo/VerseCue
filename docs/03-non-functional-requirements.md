## Measurement profiles and definitions
H-SHARED: IFC Mac mini M4, exact RAM/macOS/ProPresenter 21 build TBD, MOTU M4 clean mono channel, representative room/stream outputs/media and Companion workload captured before testing. H-LAN: same authorized ProPresenter host with dedicated companion hardware TBD and wired network; record RTT/loss/bandwidth, no invented reference performance. H-WIN: Windows 11 x64 profile hardware/build TBD; Windows 10 edition/ESU support decision required. H-INTEL: compatible Intel macOS host TBD. Pin engine/model/version, threads/acceleration, capture format and configuration for each run. No target is a vendor guarantee.

Audible reference end `t0` is independently annotated from synchronized recording; output `t7` is first frame showing correct reference/text on each intended output. Capture/STT/parse/policy/dispatch/receipt/readback use monotonic clocks. Report timestamp uncertainty and p50/p95 definition (nearest-rank on sorted complete observations), sample size, failures and exclusions. Failed/unobserved outputs are failures, not fast successes. Confirm system metric sums pre-ready processing and authorized send-to-output, excluding volunteer reaction; report wall-clock elapsed separately.
