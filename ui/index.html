3 · Free local recognition

Resident mode starts a private loopback worker only when audio is processed. Requires whisper-server beside the CLI. The model stays loaded; WAV bytes travel in memory. Stop terminates the worker. Service performance unverified.

Apple silicon Macs use Metal; Windows PCs with an NVIDIA card use CUDA when the CUDA engine is selected. The first recognition after setup can take up to a minute while the card prepares. Untick to force the processor (CPU).

Set up NVIDIA graphics card

For Windows PCs with an NVIDIA card (for example an RTX 4070). VerseCue does not download or include NVIDIA files. Download these two official ZIP files yourself, then choose them below:

  1. whisper.cpp CUDA 11.8 build, release b5454 (github.com/ggml-org/whisper.cpp)
  2. NVIDIA cuBLAS 11.11.3.6 for Windows x64 (developer.download.nvidia.com)

VerseCue checks each file against its official SHA-256 checksum, unpacks them into its own folder, checks that the card is detected (the first check can take about a minute) and then uses the card. The built-in speech model stays the same.

Use an official whisper.cpp build for this operating system. No cloud provider, download or purchase is required by this app.
